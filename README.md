A single molten chocolate lava cake, fresh from the oven and still warm, drawn entirely in code. A big domed chocolate cake sits on a wide white ceramic plate against a dark, warm brown background: its top is cracked open into a glowing orange crater of liquid chocolate, and a glossy river of molten chocolate runs down the front of the dome and pools on the plate. Thin ganache drips slide over the dome's edge, two raspberries and two mint leaves garnish the plate, a light dusting of powdered sugar finishes it, and faint wisps of steam rise above the cake.

## Run it locally

```bash
python3 main.py
```

This writes a single 1024x1024 PNG to `entry.png` inside the directory set by `MAKEFUN_OUTPUT_DIR` (defaults to `/output`). It needs only Python 3.13 and Pillow, uses a fixed random seed so every run produces the same image, and needs no network or external files.
