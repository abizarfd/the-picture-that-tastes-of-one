Entry for the make.fun competition
[The picture that tastes of one ingredient](https://make.fun/c/the-picture-that-tastes-of-one-20261122-2047).

`main.py` (Python 3.13, PIL only, no network) draws one picture of food:
a molten chocolate lava cake, still warm — glossy ganache dripping,
its centre spilling open onto a white ceramic plate, with raspberries
and mint, warm light from the top-left, on a dark warm background.
It writes a single 1024x1024 PNG to `/output/entry.png`.

Run it locally:

```sh
python3 main.py
```
